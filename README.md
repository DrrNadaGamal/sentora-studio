# Sentora Studio

Bilingual (English default, Arabic RTL) website for Sentora Studio, a one-person web studio by Nada Gamal.
Describe an idea in one sentence, get a fixed quote, pay per project.

- Static pages generated by `node build.mjs` from `content.mjs` (EN + AR strings) into `public/`.
- `api/intake.js`: Vercel function that stores intake-form submissions in a private Vercel Blob store.
- Work screenshots are of the author's own demo projects (synthetic data).
- Pages are `noindex` until launch is approved.

Design, copy and code are original. AI-assisted build, reviewed and tested in a real browser.
